# 180° SG90 机械结构 v1

这是给本项目使用的第一版可打印结构。它采用“偏心定量转子”，不是让舵机直接掀开一块大闸门：

```text
粮仓 → 上方装粮口 → 转子固定容积孔 → 旋转 180° → 下方出粮口 → 鱼缸
                                      ↘ 回到关闭位
```

一次动作只执行一次：转子在关闭位装满，转到倒粮位，停留后回到关闭位。网页已经固定为一次动作，不再有 1/2/3 份选择。

## 文件和导出

主文件是 [`fish_feeder_v1.scad`](fish_feeder_v1.scad)。用 OpenSCAD 打开后，修改文件顶部的 `part`：

```scad
part = "base";           // 基座和上下导流板
part = "rotor";          // 定量转子
part = "hopper";         // 鱼粮仓和安装法兰
part = "lid";            // 可拆卸上盖
part = "servo_bracket";  // SG90 舵机托架
part = "assembly";       // 装配预览
```

按 `F6` 渲染，再选择 `File → Export → Export as STL`。每个零件单独导出，不要直接把 `assembly` 导出打印。

这份仓库没有内置 STL，因为 STL 不是参数化源文件；朋友可以按鱼粮大小调整 `cup_r` 和 `rotor_t` 后重新导出。推荐先打印默认转子，实际称量后再做第二个转子。

## 推荐尺寸

- 基座：90 × 90 × 30 mm
- 粮仓：约 1 L 级别，顶部约 115 × 95 mm
- 默认定量孔：直径 19 mm、厚度 9 mm，理论容积约 2.55 mL
- 转子与腔体径向间隙：约 1.2 mm，轴向间隙约 1 mm；顶部间隙兼作刮料面，适合普通 FDM
- SG90 托架内腔：约 24 × 16 × 30 mm
- 舵机信号轴：基座中心，NodeMCU D1/GPIO5

默认孔容积只是几何容积，不等于鱼粮重量。不同颗粒鱼粮的堆积密度不同，必须实测 20 次出粮量后再决定是否调整转子。

## 打印设置

优先使用 PETG；设备长期户外或日晒使用 ASA。PLA 只适合室内验证。

- 层高 0.20 mm，喷嘴 0.4 mm
- 墙数 4，顶部/底部 5 层
- 基座、转子、舵机托架填充 40%
- 粮仓和盖子填充 15%～20%
- 转子平放打印，定量孔轴线竖直
- 基座底面朝下，粮仓大口朝上
- 打印后去除转子孔和基座腔体内的毛刺
- 粮食接触面可贴一层可更换的食品级薄片，或使用食品级 PP 内胆

朋友打印前必须确认：打印机能打印至少 120 × 100 mm 的平面；如果平台不够大，把粮仓改成两片式或缩小顶部尺寸。

## 五金和装配

建议准备：

- SG90 180°定位舵机 1 个
- 原装 SG90 单臂舵机摇臂 1 个，摇臂螺丝 1 个
- M3 × 10 或 M3 × 12 螺丝 8～12 个
- M2 × 8 螺丝 2～4 个，用于把摇臂固定到转子
- 2.5～3 mm 硅胶垫或薄泡棉 1 张，夹在粮仓法兰和基座之间
- 1000uF 电解电容，接在舵机 5V 与 GND 附近
- IP65 级电子防水盒约 100 × 68 × 50 mm 1 个，放 NodeMCU、接线端子和保险丝
- PG7/PG9 防水电缆接头 2 个，分别走舵机线和电源线

装配顺序：

1. 先不接鱼粮，把转子放入基座腔体，确认转子可以无明显卡滞地转动。
2. 将 SG90 插入底部托架，舵机输出轴朝上，对准基座中心孔；托架用 M3 螺丝固定。
3. 舵机通电后设置为关闭角度，安装原装舵机摇臂，再用 M2 螺丝把摇臂固定到转子底部孔位。不要在舵机顶到机械限位时硬拧。
4. 粮仓法兰与基座之间放薄泡棉，四角用 M3 螺丝固定；泡棉是防漏粮和减振，不要涂永久胶。
5. 盖子只需压入定位边，保留可拆卸性；粮仓内放干燥剂时，干燥剂必须与鱼粮隔离。
6. 先装空仓，网页选择 180°模式：关闭角度对应装粮位，打开角度对应倒粮位，去程和回程先设 1000 ms。

电子部分不要和粮仓做成一个打印腔体。推荐把 NodeMCU、接线端子和电容放到旁边的 IP65 成品盒里，盒子底部朝下、线缆从防水接头进入；打印外壳只负责粮仓、转子和舵机支撑，维护和防水会更可靠。

## 校准步骤

1. 舵机脱离粮仓负载，确认关闭位是转子孔对准上方进粮口。
2. 点击“测试当前舵机”，确认转子转到 180°后，孔对准下方出粮口，再回到关闭位。
3. 放入 10～20 粒干燥鱼粮，测试是否能完全从出粮口落下。
4. 称量 20 次，记录平均值和最大偏差；如果出粮太少，增大 `cup_r` 或 `rotor_t`；如果太多，减小它们。
5. 观察转子边缘是否夹粮。若夹粮，降低粮仓出口高度、打磨毛刺，或把 `rotor_r` 增加 0.3～0.5 mm。
6. 连续空载/装粮运行至少 100 次，确认 SG90 不发热、NodeMCU 不重启、出粮口不积粮，再无人值守运行。

## 机械限制

这个版本没有位置传感器，关闭位和倒粮位依赖 SG90 的机械安装与网页角度参数。不要让舵机堵转当限位；如果转子卡粮，应先断电清理。后续若要更高可靠性，可在基座加一个槽型光电开关检测关闭位，再增加落料光电传感器确认鱼粮确实落下。
