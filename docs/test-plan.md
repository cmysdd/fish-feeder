# 测试与验收清单

## 1. 电气测试

- [ ] NodeMCU USB 烧录稳定，串口没有反复重启。
- [ ] 舵机使用外部 5V 电源，不接 ESP8266 3.3V。
- [ ] NodeMCU 与舵机电源共地。
- [ ] 舵机附近安装 470～1000uF 电容。
- [ ] 舵机启动时 5V 电压没有明显跌落。
- [ ] 连续动作 20 次，NodeMCU 不重启。

## 2. 舵机与机械测试

- [ ] 上电后量杯处于关闭/装粮位置。
- [ ] 一份命令只完成一次打开—关闭循环。
- [ ] 两份和三份分别完成对应次数循环。
- [ ] 舵机不会撞击机械限位或持续嗡鸣。
- [ ] 空载连续运行 100 次无卡死。
- [ ] 装粮连续运行 100 次无明显漏投或双投。
- [ ] 20 次单份称重的误差满足实际养鱼需求。
- [ ] 粮仓盖、防潮和出粮口位置合理。

## 3. 网络连接测试

- [ ] ESP8266 能连接家庭 2.4GHz Wi-Fi。
- [ ] 串口显示 MixIO MQTT connected。
- [ ] 网页通过家庭 Wi-Fi 连接 MixIO。
- [ ] 网页通过手机 4G/5G 连接 MixIO。
- [ ] 网页能立即读取保留的设备状态。
- [ ] 路由器重启后 ESP8266 自动恢复连接。
- [ ] 手机网络切换后网页自动重连。

## 4. 命令安全测试

- [ ] 正确签名命令可以执行。
- [ ] 修改网页签名密钥后命令被 `invalid_signature` 拒绝。
- [ ] 重复发送同一个 UUID 不会再次动作。
- [ ] 超过 45 秒的命令被 `command_expired` 拒绝。
- [ ] ESP8266 尚未同步时间时不接受远程投喂。
- [ ] 一分钟内第二次投喂被 `cooldown` 拒绝。
- [ ] 达到 24 小时份量上限后继续命令被 `daily_limit` 拒绝。

## 5. 断电和故障测试

- [ ] 正常待机时断电，恢复后不会自动投喂。
- [ ] 收到命令但舵机动作前断电，恢复后相同 UUID 不会重跑。
- [ ] 舵机动作期间断电，恢复后不会再次执行相同命令。
- [ ] ESP8266 离线时网页投喂按钮不可用。
- [ ] 设备意外掉线后网页收到离线遗嘱或在 180 秒内状态超时。
- [ ] 页面等待确认超时后提示人工检查，而不是自动重试。

## 6. 定时计划测试

- [ ] 可以新增、编辑、停用、启用和删除计划。
- [ ] 计划重新读取后与网页保存内容一致。
- [ ] 网页关闭、手机锁屏后计划仍按北京时间执行。
- [ ] 周一到周五、周末和自定义星期掩码分别正确。
- [ ] 相同日期和时间的冲突计划被网页阻止。
- [ ] 手动投喂后一分钟内到期的计划被安全间隔跳过。
- [ ] 达到 24 小时份量上限后，计划不会继续出粮。
- [ ] 计划执行时断电，恢复后当天不会再次执行同一条计划。
- [ ] 设备完成过 NTP 校时后，MixIO 临时不可达时计划仍能执行。
- [ ] 设备冷启动且无法校时时，不会使用错误时间盲目投喂。

## 7. 长期运行测试

- [ ] 连续上电 24 小时无内存持续下降。
- [ ] 连续上电 7 天无异常重启。
- [ ] 每天按计划进行数次自动投喂。
- [ ] MixIO 暂时不可达时仅执行已保存的本地计划，不接受新远程命令。
- [ ] 网络恢复后只处理新鲜且有效的命令。
- [ ] 舵机和电源在封闭外壳内温度可接受。

## 8. 上线验收条件

必须同时满足：

1. 100 次装粮动作没有危险的重复投喂。
2. 断电、重启和 MQTT 重连不会自动触发旧命令。
3. 手机流量下至少完成 10 次端到端测试。
4. 投喂份量已经称重校准。
5. 供电、外壳和固定方式适合鱼缸潮湿环境。
6. 用户理解“completed 只代表舵机完成”，没有落料传感器时仍需定期检查。
7. 定时计划经过至少 7 天闭屏运行和一次断电恢复测试。
