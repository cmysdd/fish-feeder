# 硬件采购、供电、接线和机械结构

## 1. 最小采购清单

| 数量 | 模块 | 推荐规格 | 参考用途 |
|---:|---|---|---|
| 1 | ESP8266 开发板 | NodeMCU ESP-12E/ESP-12F，CH340 或 CP2102 | Wi-Fi 和逻辑控制 |
| 1 | 舵机 | MG90S 180°金属齿轮 | 驱动旋转量杯 |
| 1 | 电源 | 稳压 5V 2A | 给开发板和舵机供电 |
| 1 | 电解电容 | 1000uF，耐压 10V 或更高 | 抑制舵机启动压降 |
| 若干 | 杜邦线或接线端子 | 按模块接口选择 | 信号和供电连接 |
| 1 | USB 数据线 | 必须支持数据传输 | 固件烧录 |
| 1 | 投喂机械件 | 旋转量杯、粮仓、固定支架 | 定量落料 |

若机械负载非常轻，可以使用 SG90；MG90S 的金属齿轮更耐久，适合长期反复动作。不要购买连续旋转舵机，因为连续舵机只能控制方向和速度，不能可靠回到固定角度。

## 2. 接线表

MG90S 常见线色：

| 舵机线 | 连接位置 |
|---|---|
| 棕色或黑色 | 5V 电源 GND |
| 红色 | 5V 电源正极 |
| 橙色或黄色 | NodeMCU D1（GPIO5） |

NodeMCU GND 必须与舵机电源 GND 连接在一起，否则舵机信号没有共同参考电位。

```text
NodeMCU D1 / GPIO5 ───────────── 舵机信号线

5V 电源正极 ──┬─────────────── 舵机红线
              └─────────────── NodeMCU VIN/5V

5V 电源负极 ──┬─────────────── 舵机棕/黑线
              └─────────────── NodeMCU GND

1000uF 电容接在舵机附近的 5V 与 GND 之间
电容正极接 5V，带条纹的负极接 GND
```

ESP8266 的 3.3V GPIO 信号通常可以直接控制 MG90S，但不能使用 ESP8266 的 3.3V 引脚给舵机供电。MG90S 堵转或快速启动时电流可能明显升高，必须使用稳定的外部 5V 电源。

### 配网重置按键

本固件默认使用 NodeMCU 的 `FLASH` 按键（GPIO0/D3）作为强制配网输入，不需要额外购买按键。设备正常运行时，按住 `FLASH`，再按一下 `RST`，松开后会清除已保存 Wi-Fi 并开启 `fish-feeder-xxxx` 配置热点。也可以快速连续按两次 `RST` 触发同样的配网模式。不要在烧录时长按 `FLASH`，否则开发板可能进入下载模式。

如果你的板子没有可用的 `FLASH` 键，可以在 `D3` 和 `GND` 之间接一个常开轻触按键，并在上电/复位时按住它。

## 3. 烧录和正式运行时的供电

### 烧录阶段

1. USB 只给 NodeMCU 供电和传输数据。
2. 舵机使用独立 5V 电源。
3. 舵机电源 GND 与 NodeMCU GND 共地。
4. 不要把外部 5V 正极再接到 NodeMCU VIN，避免两路 5V 电源互相回灌。

### 正式运行

拔掉电脑 USB 后，可以使用同一只 5V 2A 电源并联给 NodeMCU VIN/5V 和舵机供电。不同 NodeMCU 克隆板的电源保护方式不同，正式运行时不要同时插着电脑 USB 和外部 VIN 供电。

## 4. 机械结构选择

### 推荐：旋转量杯

```text
上方粮仓
   ↓
[量杯处于装粮位置]  ← SERVO_CLOSED_ANGLE
   │ 舵机旋转
[量杯处于倒粮位置]  ← SERVO_OPEN_ANGLE
   ↓
鱼缸
```

量杯的容积决定单份鱼粮。固件中的“2 份”就是完整执行两次装粮—倒粮—回位动作。

优点：

- 份量比按时间打开闸门稳定。
- 180°普通舵机即可完成。
- 回位后自动准备下一份。
- 软件不需要根据鱼粮流速计算开门时间。

### 不推荐：单纯翻板闸门

闸门结构虽然最简单，但每次落料量会受颗粒大小、仓内压力、湿度和打开时间影响。鱼粮受潮后容易形成架桥，舵机动作完成却没有实际落料。

## 5. 舵机角度校准

`config.h` 中的默认值：

```cpp
#define SERVO_CLOSED_ANGLE 12
#define SERVO_OPEN_ANGLE 92
#define SERVO_OPEN_MS 550
#define SERVO_SETTLE_MS 450
```

第一次测试时不要安装舵臂：

1. 烧录后上电，舵机自动移动到关闭角度。
2. 断电后再安装舵臂，使量杯处于装粮位置。
3. 空载执行一份，观察倒粮角度。
4. 每次只调整 3～5°，避免舵机撞到机械限位。
5. 舵机在终点持续嗡鸣通常说明角度超过机械行程，应立即减小角度。

不要依靠舵机堵转作为机械限位。长期堵转会导致电流上升、齿轮磨损和 ESP8266 重启。

## 6. 粮仓与环境

- 粮仓使用食品接触安全、无异味的材料。
- 增加密封盖和干燥剂空间，避免鱼缸水汽进入。
- 出粮口远离过滤泵水花和增氧气泡。
- 电路板和接线端子放在鱼缸水线以上。
- 电源线做拉力缓解，不能依靠杜邦线悬挂设备。
- 正式使用时采用螺丝端子或焊接，不使用松动的面包板连接。

## 7. 建议的第二阶段传感器

| 传感器 | 作用 | 优先级 |
|---|---|---|
| 槽型光电开关 | 检测量杯是否回到原位 | 高 |
| 对射光电或落料传感器 | 判断是否真的有鱼粮落下 | 高 |
| 1kg 称重传感器 + HX711 | 估算粮仓余量 | 中 |
| DS18B20 防水探头 | 读取鱼缸水温 | 中 |
| 漏水传感器 | 鱼缸附近积水报警 | 中 |

第一版没有位置和落料反馈，因此网页中的“完成”仅表示舵机动作序列执行完毕。
