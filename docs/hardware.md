# 硬件采购、供电、接线和机械结构

## 1. 最小采购清单

| 数量 | 模块 | 推荐规格 | 参考用途 |
|---:|---|---|---|
| 1 | ESP8266 开发板 | NodeMCU ESP-12E/ESP-12F，CH340 或 CP2102 | Wi-Fi 和逻辑控制 |
| 1 | 舵机 | SG90 180°定位舵机（推荐）或360°连续旋转舵机 | 驱动旋转量杯 |
| 1 | 电源 | 稳压 5V 2A | 给开发板和舵机供电 |
| 1 | 电解电容 | 1000uF，耐压 10V 或更高 | 抑制舵机启动压降 |
| 若干 | 杜邦线或接线端子 | 按模块接口选择 | 信号和供电连接 |
| 1 | USB 数据线 | 必须支持数据传输 | 固件烧录 |
| 1 | 投喂机械件 | 旋转量杯、粮仓、固定支架 | 定量落料 |

连续旋转舵机只能控制方向和速度，不能直接知道绝对角度，因此本项目用运行时间估算角度并自动反转回位；如果需要精确定位，选择180°定位舵机或增加位置传感器。若机械负载较大，选带金属齿轮、额定5V的连续舵机。

## 2. 接线表

舵机常见线色（以你手上标签为准）：

| 舵机线 | 连接位置 |
|---|---|
| 棕色或黑色 | 5V 电源 GND |
| 红色 | 5V 电源正极 |
| 橙色或黄色 | NodeMCU D1（GPIO5） |

NodeMCU GND 必须与舵机电源 GND 连接在一起，否则舵机信号没有共同参考电位。

```text
NodeMCU D1 / GPIO5 ───────────── 舵机信号线

5V 电源正极 ──┬─────────────── 舵机红线
              └─────────────── NodeMCU VIN/5V

5V 电源负极 ──┬─────────────── 舵机棕/黑线
              └─────────────── NodeMCU GND

1000uF 电容接在舵机附近的 5V 与 GND 之间
电容正极接 5V，带条纹的负极接 GND
```

ESP8266 的 3.3V GPIO 信号通常可以直接控制 MG90S，但不能使用 ESP8266 的 3.3V 引脚给舵机供电。MG90S 堵转或快速启动时电流可能明显升高，必须使用稳定的外部 5V 电源。

### 配网重置按键

本固件默认使用 NodeMCU 的 `FLASH` 按键（GPIO0/D3）作为强制配网输入，不需要额外购买按键。设备正常运行时，按住 `FLASH`，再按一下 `RST`，松开后会清除已保存 Wi-Fi 并开启 `fish-feeder-xxxx` 配置热点。也可以快速连续按两次 `RST` 触发同样的配网模式。不要在烧录时长按 `FLASH`，否则开发板可能进入下载模式。

如果你的板子没有可用的 `FLASH` 键，可以在 `D3` 和 `GND` 之间接一个常开轻触按键，并在上电/复位时按住它。

## 3. 烧录和正式运行时的供电

### 烧录阶段

1. USB 只给 NodeMCU 供电和传输数据。
2. 舵机使用独立 5V 电源。
3. 舵机电源 GND 与 NodeMCU GND 共地。
4. 不要把外部 5V 正极再接到 NodeMCU VIN，避免两路 5V 电源互相回灌。

### 正式运行

拔掉电脑 USB 后，可以使用同一只 5V 2A 电源并联给 NodeMCU VIN/5V 和舵机供电。不同 NodeMCU 克隆板的电源保护方式不同，正式运行时不要同时插着电脑 USB 和外部 VIN 供电。

## 4. 机械结构选择

### 推荐：旋转量杯

```text
上方粮仓
   ↓
[量杯处于装粮位置]  ← SERVO_CLOSED_ANGLE
   │ 舵机旋转
[量杯处于倒粮位置]  ← SERVO_OPEN_ANGLE
   ↓
鱼缸
```

量杯的容积决定每次动作的鱼粮量。当前网页每次只执行一次装粮—倒粮—回位动作。

优点：

- 出粮量主要由量杯容积和机械结构决定。
- 180°普通舵机即可完成。
- 回位后自动准备下一份。
- 软件不需要根据鱼粮流速计算开门时间。

### 不推荐：单纯翻板闸门

闸门结构虽然最简单，但每次落料量会受颗粒大小、仓内压力、湿度和打开时间影响。鱼粮受潮后容易形成架桥，舵机动作完成却没有实际落料。

## 5. 舵机角度校准

本项目针对你的 180° SG90，推荐使用仓库中的参数化机械结构：[mechanical/README.md](../mechanical/README.md)。它使用固定容积转子量杯，转子孔先在上方装粮，再转到下方出粮口，避免 SG90 直接承受整仓鱼粮压力。

固件默认值（也可以在网页“投喂参数”中修改并保存到设备）：

```cpp
#define SERVO_CLOSED_ANGLE 90
#define SERVO_OPEN_ANGLE 180
#define SERVO_OPEN_MS 550
#define SERVO_SETTLE_MS 450
#define SERVO_MODE_DEFAULT 1
#define SERVO_POSITIONAL_MOVE_MS 1000UL
#define SERVO_ACTION_PAUSE_MS 1000UL
#define SERVO_POSITIONAL_RETURN_MS 1000UL
#define SERVO_CONTINUOUS_TURN_DEGREES 90
#define SERVO_CONTINUOUS_MS_PER_REV 4000UL
#define SERVO_CONTINUOUS_FORWARD_US 1700
#define SERVO_CONTINUOUS_REVERSE_US 1300
#define SERVO_CONTINUOUS_STOP_US 1500
```

网页默认使用180°定位舵机模式。对于机械转子量杯，先把关闭角度校准到转子孔对准上方装粮口，再把打开角度校准到孔对准下方出粮口，建议先用10°和170°，避免长期顶住舵机两端。180°定位模式使用“起始位置 + 方向 + 相对角度”，并以小步插值控制去程和回程时间。顺逆时针会受舵机安装方向影响，首次必须空载确认。360°连续舵机仍可手动切换，但不适合这套精确定量转子。

当前固件在180°模式使用500～2400us定位脉宽，以覆盖常见SG90的完整机械行程。保存180°模式参数时，设备会立即移动到起始位置；投喂时再执行“去程→停留→回程”。设定时间不能突破舵机自身速度上限：如果负载下90°实际至少需要1.3秒，即使网页填写1秒也无法让舵机物理上更快。如果网页测试完全没有动作，烧录 `firmware/servo_diagnostic/servo_diagnostic.ino` 排查。

第一次测试时不要安装舵臂：

1. 连续模式烧录后上电，舵机应保持停止，不应自行转动。
2. 先不装鱼粮，设置一圈耗时并测试180°转动，按实际转速微调。
3. 安装量杯后，用少量鱼粮测试一次出粮，调整转动角度和方向。
4. 如果切换到180°模式，断电后安装舵臂到关闭位置，再逐步调整两个定位角度。
5. 连续舵机停止脉宽通常约1500us；若仍慢慢转，用高级校准把停止脉宽调整到实际静止值。

不要依靠舵机堵转作为机械限位。长期堵转会导致电流上升、齿轮磨损和 ESP8266 重启。

## 6. 粮仓与环境

- 粮仓使用食品接触安全、无异味的材料。
- 增加密封盖和干燥剂空间，避免鱼缸水汽进入。
- 出粮口远离过滤泵水花和增氧气泡。
- 电路板和接线端子放在鱼缸水线以上。
- 电源线做拉力缓解，不能依靠杜邦线悬挂设备。
- 正式使用时采用螺丝端子或焊接，不使用松动的面包板连接。

## 7. 建议的第二阶段传感器

| 传感器 | 作用 | 优先级 |
|---|---|---|
| 槽型光电开关 | 检测量杯是否回到原位 | 高 |
| 对射光电或落料传感器 | 判断是否真的有鱼粮落下 | 高 |
| 1kg 称重传感器 + HX711 | 估算粮仓余量 | 中 |
| DS18B20 防水探头 | 读取鱼缸水温 | 中 |
| 漏水传感器 | 鱼缸附近积水报警 | 中 |

第一版没有位置和落料反馈，因此网页中的“完成”仅表示舵机动作序列执行完毕。
