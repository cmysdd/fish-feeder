# ESP8266 + MixIO 远程鱼食投喂器

这是一个不自建服务器、不使用数据库、没有视频功能的远程鱼食投喂器。手机打开自己设计的网页，网页通过 MixIO 的 MQTT over WebSocket 接口发送命令；ESP8266 连接 MixIO MQTT 后驱动 MG90S 舵机完成投喂。

```text
手机自定义网页
    │ WSS 8084（加密）
    ▼
MixIO 免费主站
    ▲
    │ MQTT 1883 + HMAC 命令签名
    │
ESP8266 ── MG90S 舵机 ── 旋转量杯投喂机构
```

GitHub Pages 只负责免费托管静态 HTML、CSS 和 JavaScript，不运行后端函数。网页外观、按钮、状态显示和操作记录全部由本项目控制，不需要使用 MixIO 自带项目页面。

## 已实现功能

- 手机网页点击“立即投喂”执行一次完整动作
- 网页默认使用360°连续旋转舵机，也可切换180°定位舵机；两种模式都支持“去程→停留→回程”动作，180°模式可设置方向、角度和去/回程时间，参数保存在设备 EEPROM
- 最多 6 条设备本地定时计划，可设置时间、星期和启停状态；每条计划每次执行一次动作
- 定时计划保存在 ESP8266 EEPROM，手机关机或网页关闭后仍会执行
- MixIO WSS 实时连接和设备在线状态
- Wi-Fi 信号、剩余内存、固件版本、最近投喂时间
- 首次上电自建配网热点，Wi-Fi 凭据保存到 ESP8266 闪存
- 正常在线时从网页打开局域网设置页修改 Wi-Fi
- Wi-Fi 失效自动回退配网热点，支持双击 RST 强制重置
- 手机本地保存最近 30 条操作记录
- 每条命令带 UUID、签发时间、45 秒有效期和 HMAC-SHA256 签名
- ESP8266 EEPROM 保存最近命令、定时计划、最近投喂时间和 24 小时执行次数
- 防重复命令、防离线旧命令、防短时间连续投喂
- MQTT 断线自动重连、遗嘱消息和状态查询
- 舵机执行前先保存安全状态，执行中断电也不会重复运行同一命令
- 参数面板提供签名的“测试当前舵机”命令，不占用投喂次数，便于排查180°舵机接线和角度设置
- 多手机私密授权链接，导入后自动清除地址栏凭据
- 移动端计划卡片、操作提示、回到前台自动刷新和成功振动反馈

## 最短落地路径

1. 购买 NodeMCU ESP8266、MG90S、5V 2A 电源和 1000uF 电容。
2. 注册 MixIO 账号并创建私有账号项目，记录用户名、项目名和项目密码。
3. 在第一台手机的“手机授权”中填写项目密码和命令签名密钥。
4. 其他可信手机可通过“复制授权链接”一次性导入相同配置；链接等同于钥匙，不要公开。
5. 按文档接线，烧录固件；Wi-Fi 不写进代码，首次上电用设备热点配置。
6. 把本目录推送到 GitHub，启用 GitHub Pages，手机使用生产 HTTPS 地址。
7. 在网页新增定时计划，等待设备回传并关闭网页验证自动执行。
8. 完成至少 100 次空载和装粮测试后再无人值守运行。

## 成本与限制

软件路线可以不产生固定月费，但 MixIO 和 GitHub Pages 的免费政策可能调整。硬件预计约 45～100 元，取决于是否已有 ESP8266、电源和机械外壳。

MixIO 为 ESP8266 提供的标准 MQTT 端口是 1883，设备到 MixIO 的传输不加密。本项目用额外的 HMAC 命令签名防止伪造投喂命令，但不能隐藏状态数据，也不能阻止网络层拒绝服务。更高安全等级需要自建 TLS MQTT、家庭 VPN，或改用能够稳定运行 WSS/TLS 的方案。

“投喂完成”表示舵机动作序列完成，不代表传感器已经确认鱼粮落下。长期无人值守版本应增加落料检测或称重反馈。
